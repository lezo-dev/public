# Support Questovery

Dernière mise à jour : 27 mai 2026.

Pour toute question concernant Questovery, vous pouvez contacter l'équipe support par e-mail à l'adresse support@questovery.com.

Merci d'indiquer, lorsque cela est utile, l'organisation concernée, la quête, l'équipe, l'adresse e-mail du compte, le type d'appareil, la version de l'application et une description précise du problème rencontré.

Les demandes sont traitées selon leur nature, leur criticité et les conditions de service applicables au compte ou à l'organisation concernée.
